# hannammaltu

한남말투 프로그래밍 언어(한남말투랭)  
`Brainfuck`을 참고해 제작했습니다.  

## 확장자

파일 확장자는 `*.hnm`을 사용합니다.

## REPL

한남말투를 아무 인수 없이 실행하면 REPL 모드로 실행됩니다.  

|키워드|설명|
|-|-|
|.exit|한남말투랭을 종료합니다.|
|.debug|현재 인스턴스의 변수의 값을 출력합니다.|

## 주요 키워드

|키워드|설명|
|-|-|
|아 예?|포인터를 감소합니다.|
|예?|포인터를 증가합니다.|
|티~원|가리키는 포인터에 값을 1 추가합니다.|
|아뇨아뇨아뇨|가리키는 포인터에 값을 1 감소합니다.|
|엄|가리키는 포인터의 값을 제곱합니다.|
|요이|가리키는 포인터에 아스키 코드 값을 입력받습니다.|
|쥐~랄|가리키는 포인터를 아스키 코드로 출력합니다.|
|줴줴이야|이 키워드가 실행될 때의 가리키는 포인터의 값이 0이 되면 다음으로 오는 `넌 나가라`로 이동합니다.|
|넌 나가라|이 키워드가 실행될 때의 가리키는 포인터의 값이 0이 아니면 다음으로 오는 `줴줴이야`로 이동합니다.|

위 키워드 이외의 명령들은 모두 주석으로 간주합니다.  

## 기호

|기호|설명|
|-|-|
|+|앞 명령어와 뒤 명령어를 한 줄로 잇습니다. (예시: `티~원+티~원` => 2 추가)|
